# TSK9 - Teori Sistem Kuadrat 9

📘 Sistem berpikir numerik reflektif berdasarkan pola digital root dari bilangan kuadrat.

## 🎯 Tujuan
- Menyusun struktur berpikir melalui matematika sederhana
- Membentuk pola numerik konsisten
- Membangun alat bantu logika reflektif
